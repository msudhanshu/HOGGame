Drop silhouette PNGs/JPGs here. The Pack Silhouette GUI lists this folder in its dropdown.

Tips:
- Use a solid filled shape (not a thin outline) so flood mask has interior pixels.
- Dark / black silhouettes are OK for the shape. Keep Pack "Min brightness" up (~0.55)
  and "Hunt tint" at 0 so hunt icons stay readable. Raise hunt tint only for harder levels.
